## Uninstallation, ProgramData Installation, and Documentation

### Highlights

- Added updated installation mode documentation for Run as User and Run as Administrator.
- Documented ProgramData installation behavior for administrator/all-users installs.
- Replaced the older silent installation section with current MSI and EXE silent install commands.
- Added MSI and EXE uninstall commands, including complete EXE uninstall with saved data removal.
- Added troubleshooting notes for install mode switching, UAC prompts, and uninstall command behavior.
- Added separate CMD and PowerShell examples for silent install and uninstall commands.

## Smart MOCA Client Rename & Usability Updates

Oracular MOCA Client is now called **Smart MOCA Client** to reflect Oracular's new name, Smart IS.

### Highlights

- New tab titles reflect the last command executed to make it easy to keep track of active work.
- Drag-and-drop tabs are supported for faster workspace organization.
- Tabs can be renamed from the right-click menu and restored with the saved names.
- Tabs can be color-coded from the right-click menu and restored with the saved colors.
- Tabs can be closed to the left, right, or all other tabs from the right-click menu.
- MOCA console information can be compiled and combined from clustered environments.
- Server database logs have improved parsing for easier analysis.
